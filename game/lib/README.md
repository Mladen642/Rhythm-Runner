# meSpeak (vendored)

Browser text-to-speech used for character voices when the system offers no speech voices (for example in the Linux AppImage).

- `mespeak.js`: meSpeak 2.0.2 by Norbert Landsteiner (eSpeak compiled to JavaScript), bundled for the browser with esbuild.
- `mespeak_config.json`, `en-us.json`: the meSpeak configuration and the US English voice.
